All notes

Writes like a sticky note

Title. Click the title at the top left to name the note. It is saved as the note's first #  heading, so it also names the note in All notes and the centre of the mind map.

Tab indents, Shift+Tab outdents. Enter continues a list; Enter on an empty item ends it.

Type #  for a heading, 1.  for a numbered list, -  for bullets and - [ ]  for a to-do.

Ctrl+N new · Ctrl+S save
Ctrl+B bold · Ctrl+Z undo
Press Esc, then Tab, to leave the editor.

Outline. Headings and list items with children fold from the arrow on their left. Ctrl+↑ / Ctrl+↓ fold or open the branch at the caret; add Shift for everything. The H button picks the heading size from the sections above it, and Tab / Shift+Tab on a heading moves it down / up a level.

Mind map. Ctrl+Shift+M or the map button switches views, and you can edit right in the map: click to select, the toolbar buttons or Tab add a child, Enter adds a sibling, double-click, F2 or just start typing renames, Delete removes a branch, Space folds. Drag a node onto another to move it (top or bottom edge to reorder), drag the background to pan, Ctrl+wheel or Ctrl+= / − / 0 to zoom, Ctrl+Z to undo. Every map edit is saved to the same Markdown file.

Light / dark. The sun/moon button in the title bar (Ctrl+Shift+L) flips this note between light and dark, keeping a matching shade. Fine-tune it with the Tone slider under ⋯.

Closing a window keeps its content; reopen it from All notes. Archived notes can be restored and are never deleted.

Headings, lists, to-dos, quotes and code are supported. Notes with tables, images or HTML (usually imported files) open read-only so nothing is lost.
